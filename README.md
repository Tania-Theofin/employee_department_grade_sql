# employee_department_grade_sql
SQL QUERIES
This repository contains SQL queries and solutions for scenario-based questions. The exercises explore the EMPLOYEE, DEPARTMENT, GRADE, and PROJECT tables, covering topics such as basic queries, ordering/grouping, joins, functions, and DDL/DML operations.

Database Schema
EMPLOYEE  
Employee details including employee number, name, job, manager, hire date, salary, commission, and department number.

DEPARTMENT  
Department information such as department number, name, and location.

GRADE  
Salary grade ranges defined by lower and higher salary limits.
